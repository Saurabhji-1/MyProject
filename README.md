# Survival Duration Calculator

The **Survival Duration Calculator** is a Python project designed to provide users with a new perspective on their lifespan by converting their age into various time units. This simple yet engaging program quantifies life experiences, encouraging reflection and appreciation for the time we have lived.

![Screenshot 2024-12-31 103921](https://github.com/user-attachments/assets/d1092da5-a7ff-4ba6-8e9c-f7161a831523)


## Features
- Converts user’s age into multiple time units:
  - Months
  - Weeks
  - Days
  - Hours
  - Minutes
  - Seconds
- User-friendly interface prompts the user to input their age and select a unit for conversion.

## Project Files
This repository contains the following files:

1. **PythonProject**: A comprehensive Python script that includes methods for calculating all six time units based on the user’s age.
2. **UnitWiseCalculations.py**: A script where the calculations for each time unit (months, weeks, days, hours, minutes, seconds) are implemented separately.

3. Follow the prompts to input your age and select a time unit to calculate your survival duration in that unit.

## Example Output
If a user inputs their age as **24 years** and selects **days**, the program calculates and displays the approximate number of days they have lived:

```
Enter your age in years: 24
Select the unit to calculate (months/weeks/days/hours/minutes/seconds): days
You have lived approximately 8760 days.
```

## Conclusion
This Python program provides a relatable and insightful way to measure life experiences across different time frames. By converting age into months, weeks, days, hours, minutes, and seconds, users can appreciate their lifespan from a fresh perspective.
